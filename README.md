# Md. Rimon Miah — Portfolio

Static portfolio website built with HTML, CSS, and vanilla JavaScript.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `RMRM01.github.io`.
2. Upload all files from this folder to the repository root—not the folder itself.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. After a few minutes, open `https://rmrm01.github.io`.

The entry file must remain named `index.html`.

## Files

- `index.html` — website content and structure
- `styles.css` — responsive design and animations
- `script.js` — mobile menu, project filters, and reveal effects
- `Rimon-Miah-CV.docx` — downloadable CV
